# Next Studio AI Business Platform

Next Studio is a bilingual business-platform demo for creating premium invoices, estimates, and proposals while showcasing a connected client workspace.

## Features

- Premium Invoice Generator
- Estimate Builder
- Proposal Builder
- AI Business Assistant
- CRM, Calendar, Analytics, and Marketplace
- Industry Templates
- English / Español interface
- Premium PDF export
- WhatsApp Assistant

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Installation

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vercel configuration: select **Vite**, use `npm run build`, and publish the `dist` directory. No environment variables are currently required.
